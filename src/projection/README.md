# Projection

## Purpose
First-Angle Orthographic Projection mathematical foundations and spatial transformations:
- Horizontal Plane (HP), Vertical Plane (VP), and Profile Plane (PP) coordinate systems
- First-angle spatial quadrant transformations (Object situated in Quadrant 1: above HP, in front of VP)
- Standard engineering folding/unfolding maths (hinging HP downwards 90° about reference line XY, folding PP outwards 90° about X1Y1)
- Front View (Elevation), Top View (Plan), and Side Views (End Elevation - Left/Right Profile Views) layout mapping
