# Sheet

## Purpose
Engineering drawing sheet composition and standard layout export:
- Standard drawing sheet formatting (ISO A2 landscape layout: 594 mm x 420 mm, margins, grid references)
- Standard engineering title block layout (projection symbol - first angle conical frustum, title, scale 1:1, student ID, date, tolerances)
- High-fidelity vector export pipeline generating SVG plots and vector PDF deliverables suitable for printing and archiving
