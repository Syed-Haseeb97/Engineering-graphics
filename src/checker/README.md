# Checker

## Purpose
Automated grading and geometric tolerance evaluation engine:
- Segment normalisation (canonical ordering, collinear segment stitching, duplicate removal, line type grouping)
- Tolerance matching (positional tolerance, angular tolerance, endpoint coincidence within calibrated thresholds in millimetres)
- Line convention validation (continuous thick outlines, dashed medium hidden lines, long-short dashed thin centerlines, continuous thin projection lines)
- Structured pedagogical feedback builder detailing missing elements, misclassified line types, dimensional deviations, and constructive hints
