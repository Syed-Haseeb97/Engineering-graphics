# Draft

## Purpose
Browser-based 2D precision drawing and drafting engine:
- High-performance 2D drawing canvas (interactive vector drafting, pan, zoom, grid)
- Magnetic geometric snaps (endpoints, midpoints, intersections, perpendiculars, tangents, XY/reference line snaps)
- Drawing command system (continuous lines, hidden dashes, projection rays, arcs, circles, bisectors, dividers)
- ISO/BIS standard dimensioning tools (linear dimensions, aligned dimensions, angular dimensions, radius, diameter)
